# 🚀 Jornada para Analista de Infraestrutura

## Sobre o Projeto

Olá! Meu nome é **Edney Rossi** e este repositório documenta minha jornada de desenvolvimento profissional na área de Infraestrutura de TI.

Atualmente atuo com suporte técnico e atendimento de chamados, realizando atividades relacionadas a:

- Suporte ao usuário final
- Active Directory
- Microsoft 365
- Criação e gestão de contas
- Licenciamento Microsoft
- Troubleshooting de estações de trabalho
- Atendimento e tratativa de chamados

O objetivo deste projeto é consolidar conhecimentos teóricos e práticos para evoluir profissionalmente para a função de **Analista de Infraestrutura de TI**.
